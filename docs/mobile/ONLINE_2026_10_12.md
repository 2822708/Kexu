## 本版内容

- 手机默认按日课表：日期切换、课程与考试卡片、课程编辑；按周与全部课程视图仍保留。
- 底部课表、专注、待办、AI 导航；更多菜单切换课表与进入设置。
- 手机考试、循环任务采用卡片，表单控件适合触摸；考试保存失败保留草稿，成功后刷新关联待办。
- AI 添加文件或截图入口；手机回车换行，使用发送按钮发送；保留逐条确认提案的业务边界。
- 安装说明、联网状态、版本更新确认、安全区域及软键盘布局适配。
- 页面按路由加载；PWA 缓存公共页面资源，API、身份、AI/SSE、备份和所有写请求直通服务器。
- 默认桌面构建不生成或注册 Service Worker。

业务数据保存在 Java 服务，首版不支持离线编辑、跨设备账号同步、后台通知或 Android 系统小组件。每个浏览器自动创建自己的空间，不会自动显示桌面版的数据。

## 解压运行包

运行包中的 `tangent-mobile.jar` 已包含页面和 H2，不需要 Android SDK、Node、Maven 或额外安装 MySQL。需要 Java 17 或以上；当前电脑已安装的 Microsoft JDK 21 可使用。

把包解压到 E 盘的新目录，例如 `E:\Tangent-Mobile`，在该目录打开 PowerShell：

```powershell
& 'C:\Program Files\Microsoft\jdk-21.0.7.6-hotspot\bin\java.exe' -jar .\tangent-mobile.jar `
  --spring.profiles.active=standalone `
  --server.address=127.0.0.1 --server.port=17827 `
  '--app.data-dir=E:/Tangent-Mobile/data' `
  --app.security.allow-local-ai-key-settings=false `
  --app.backup.enabled=false
```

看到服务启动完成后，在电脑浏览器打开 `http://127.0.0.1:17827`。首次打开自动建立当前浏览器的空间，无需手动填密钥。数据和日志位于指定的 E 盘目录；不要复用 Windows 桌面程序的用户数据目录。

手机网页演示：将启动参数中的 `--server.address=127.0.0.1` 改为 `--server.address=0.0.0.0`，电脑与手机连接同一局域网，再用手机访问 `http://电脑的局域网IP:17827`。电脑需允许该端口的局域网入站连接。此 HTTP 地址用于浏览器演示；安装为 PWA 需要可信 HTTPS，不能把电脑 IP 当作手机的 localhost。

关闭服务后，用相同数据目录重新启动。正式使用前，先用新建的测试课表和待办确认关闭、重新启动后仍能读写，再导入实际资料。当前受限运行环境的 H2 文件权限探测失败，因此本轮只验证了内存数据库接口，文件持久化及备份不能视为已验收。

未配置 AI 时，课表、考试和待办可用，AI 显示未启用。模型密钥由部署者在本地服务环境配置，不能写入前端或交付包。
