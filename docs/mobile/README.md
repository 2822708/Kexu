# 大切课程表 · 本地主数据 PWA

2026-10-18 开发验收版。分支 `feature/local-first-snapshots`。原生 Android 继续暂停。

课表、课程、考试、待办、作息、循环与专注记录写入设备 IndexedDB，核心功能不依赖 Java 或云端登录。云服务仅接收加密快照、保存必要元数据与提供应用文件；AI 是用户主动配置的可选直连服务。

## 运行

交付包与校验值见 [本地版发行目录](../../releases/mobile/local-first-2026.10.18/README.md)。解压到 E 盘普通目录，使用 Node.js 22 或更新的兼容 LTS 运行包内说明中的本机入口。源代码开发：

```powershell
cd src/frontend
npm ci
npm run build:mobile
```

同站生产部署只需要静态页面、Node 快照服务与 Nginx，不需要 Java/H2/MySQL。见 [部署说明](DEPLOYMENT.md) 与 [部署文件](../../deployment/local-first/README.md)。浏览器的 localhost 支持开发用安全上下文；手机访问电脑的 HTTP IP 地址不保证 IndexedDB/WebCrypto/PWA 安装，正式手机使用需可信 HTTPS。

## 使用

1. 首次联网打开应用并在安装说明中确认离线资源准备完成；核心页面及导入依赖全部预缓存。
2. 创建学期，录入课程、考试和待办；本机保存成功与云备份成功是两种状态。
3. 设置中导出核心 JSON。自动云备份需创建私人空间、另存恢复凭证并确认后开启。默认运行时防抖60秒、最短5分钟；关闭应用后不保证准点后台上传。
4. 新设备导入恢复凭证，下载快照并预览。只有确认“保存恢复点并替换”才替换本机核心数据；恢复清空旧AI聊天，保留设备设置和云凭据。恢复点保留最近10份。
5. 可选AI：设置兼容服务地址、模型与自己的Key，确认上下文授权。点击发送后才直连该服务；每张业务修改卡仍需逐条确认。云快照服务不代理推理。
6. 有新版本时先保存表单并等待回复结束。确认后先保存本机恢复点再刷新；其他标签页不被强制刷新。

本地 JSON 是明文；云快照为 AES-256-GCM 密文。恢复凭证包含解密密钥和空间访问权，切勿上传 GitHub。浏览器清理网站数据、无痕退出和系统存储回收仍可能清掉本机数据；文件导出与云备份不能省略。不同 origin/浏览器/设备之间不会自动合并。

## 验收与边界

本轮自动回归、浏览器离线读写、备份恢复、手机尺寸和AI协议结果见 [验收报告](ACCEPTANCE_2026_10_18.md)。AI提示词、故障评测及优化计划见 [AI报告](../ai/EVALUATION_2026-10-18.md)。

当前没有桌面H2逻辑迁移器、实时多设备合并、后台系统提醒、原生小组件；CUSTOM循环只归档文本不执行。AI历史、附件、偏好和任何Key不进入核心快照。浏览器AI直连要求供应商允许CORS/SSE。真实手机、正式HTTPS安装、真实模型质量与生产服务器可达性分别验收，不能由mock推断。
