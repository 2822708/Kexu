# 专注任务模式

状态：首版实现中

## 页面行为

- `/focus` 与课表同级，按所选日期和当前课表展示课程日程，并汇总已有待办、循环待办和考试待办。
- 课程项按学期日期、星期和周次实时从课程表生成；标记完成只记录这一次课程发生，不修改课程表。
- 临时任务复用现有待办。AI 助手可继续通过现有 `AiAction` 预览提案，用户确认后才写入待办。
- 每项课程或待办都可一键完成并显示轻量反馈。番茄时长支持 15、25、45 分钟，休息时长首版为 5 分钟。
- 同时允许多项任务和多个暂停的计时；同一时刻运行一个计时器，切换任务时暂停当前项。

## 数据与接口

- `focus_course_completion` 按账号、课表、课程和发生日期保存完成状态。
- `GET /api/focus/course-completions?scheduleId={id}&date=YYYY-MM-DD` 读取某日已完成的课程项。
- `PUT /api/focus/course-completions/{courseId}` 接受课表、日期和完成状态；后端验证课表归属及课程是否确实安排在该日期。
- 用户待办仍使用 `/api/todos`。番茄运行状态保存在本机浏览器存储中，页面重开后可恢复倒计时。

## 首版边界

- 计时器不会自动把任务标记为完成；用户需要主动确认。
- 课程完成状态保存在后端，番茄暂停状态仅保存在当前设备；首版不提供跨设备计时同步、专注历史报表或系统通知。
- Android 离线客户端尚未接入这套课程发生状态接口。
