## 已实施

| 领域 | 完成内容 |
|---|---|
| 桌面凭据和导航 | DPAPI 保存桌面凭据；启动时校验 loopback 监听进程归属；WebView2 限定精确本地 origin、阻止子框架和弹窗、将外部 HTTP(S) 导航交给系统浏览器；启动页不再把密钥放进 Java 命令行。 |
| 身份与配置权限 | 账号角色存入数据库并在服务端校验；全局节次配置、共享 AI 配置与桌面本机 AI 配置分开授权；首次空库初始化需要引导密钥；序列化响应忽略凭据字段。 |
| AI 工作区与操作提案 | 按账号、课表工作区和 scope 校验读取/写入；提案通过条件更新原子领取，验证失败不会清除旧的有效提案；未知/不完整动作不会保存为待执行卡片；AI 完成循环待办走统一服务路径。 |
| 课程表和待办一致性 | 删除课表在事务中清理关联考试、考试待办、会话绑定和待执行提案；编辑课表日期会使相关课程提案失效；周次、节次、长度和范围在 DTO 与业务服务两层校验。 |
| 循环规则 | 使用可注入的 Asia/Shanghai 时钟、有限后台线程池、持久化评估游标和有限补扫窗口；同一待办只能接出一次下一期，避免重复完成造成重复生成。 |
| AI 连接与上下文 | 断开请求可中止上游读取；总时长、静默时长和响应体大小有限制；异常、空响应和模型截断不会产出可执行提案；提示上下文和聊天历史有边界，聊天历史支持游标分页。 |
| 数据库与查询 | H2/MySQL 使用版本化 Flyway 脚本；旧库先验证既有表/列再 baseline，不认识或不完整的结构会拒绝自动迁移；新增列表分页 API 并保留旧接口兼容。 |
| 用户体验与桌面交付 | HTML 导入提供行级诊断和有界输入；AI 操作卡展示工作区与影响记录；设置页提供受限备份/预览下载，另有离线恢复脚本；桌面构建固定工具链、生成 SHA-256 文件清单并要求隔离冒烟检查。 |

## 当前仍需真实部署环境完成的事项

1. Flyway 的 H2 空库/旧库路径已由自动测试覆盖；MySQL/MariaDB 脚本尚未在真实 MariaDB 实例中升级演练。上线前应在副本执行一次迁移并核对角色、循环游标和提案字段。
2. 未准备固定版本 WebView2 Runtime，因此没有生成可发布 Windows 包，也没有宣称固定 Runtime 发布冒烟已通过。`build-desktop.ps1` 的固定 Runtime 构建参数与验证脚本已备好。
3. DeepSeek 上游真实服务、代理环境和实际模型响应尚未做端到端测试；超时、取消和响应边界的实现不能代替供应商联调。
4. 新增分页目录 API 与 AI 会话游标分页已可供客户端使用；旧的课程、考试、待办接口仍保留，主界面当前仍依赖兼容的全量目录接口。大规模账户可在后续客户端分页切换中继续降低首屏载荷。
5. 桌面备份恢复需在目标 Windows 用户目录下用测试副本演练；DPAPI 凭据仍绑定原 Windows 用户，换用户迁移需要重新建立登录凭据。
