Android

Android 8.0 及以上 · APK 安装包

下载 Android APK

Kexu-Android-2026.10.20.apk · 3.0 MB

  1. 在手机上下载，完成后打开 APK 文件。
  2. 按系统提示允许当前来源安装应用，再完成安装。
  3. 打开 Kexu，建立课表和今日任务。

已有版本？直接覆盖安装。升级前导出 JSON 备份，勿先卸载或清除应用数据。本版沿用原应用 ID 与发布签名。

Windows

Windows 10 / 11 · 64 位便携版

下载 Windows 便携包

Kexu-Windows-x64.zip · 1.4 MB

  1. 完整解压 ZIP，例如放在 E:\Apps\Kexu。
  2. 打开文件夹，双击 Kexu.exe；请保留其他文件。
  3. 若缺少 WebView2，从 Microsoft 官网安装 Evergreen Runtime 后重试。需要 .NET Framework 4.8。

已有版本？先退出并备份旧文件夹；替换程序时保留 Data 和已有的 kexu-data-dir.txt。这是便携版，没有安装向导。

数据跟随设备

Windows 默认保存在程序旁的 Data 文件夹，整个程序目录可放在 E 盘。Android 数据由手机系统管理。跨设备请导出 JSON，再在目标端预览并确认导入。

核心功能离线可用

原生程序无需 Java 或 Node。AI 与云快照需单独配置网络服务；原生云备份还需要服务端跨域配置与联调，本包不附带 API 密钥。
