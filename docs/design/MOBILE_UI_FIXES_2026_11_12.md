# 手机端控件修正（2026-11-12）

本轮来自真机截图反馈的四处界面问题。记录根因、改动与验证边界，便于后续复验。

## 1. AI 图标按钮的图标不居中

**现象**：AI 页头部「对话（时钟）」「新对话（+）」和输入区「发送（纸飞机）」的图标看起来偏左。

**根因**：移动端用 `font-size: 0` 隐藏按钮文字，但文字节点仍留在 antd 的 flex 布局里，antd 在图标与文字之间固定加 8px 间距。文字宽度为 0，间距不变，于是内容宽度变成 `16 + 8 + 0`，居中后图标左侧只分到 2px、右侧分到 10px，图标偏左 4px。

实测（390px 视口）：三个按钮均为 44×44，图标横向偏移 `-4px`，纵向 0。

**改动**：`settings-ai.css` 在窄屏下把 `> .ant-btn-icon + span` 直接 `display: none`，并把头部两个按钮的 `padding-inline` 收为 0；`assistant-send-button` 去掉 `font-size: 0`。三个按钮都已有 `aria-label`，去掉文字不影响读屏。

**实测**：修复后三个按钮图标横向偏移均为 `0px`。

## 2. 设置里「启用AI助手」开关多出一块灰色

**现象**：开关看起来比周围控件大，下方多出一条灰色。

**根因**：`mobile.css` 里窄屏规则 `.ant-switch { min-height: 28px }` 只把**轨道**从 22px 拉到 28px，antd 的圆点仍是 18px 且固定 `top: 2px`，于是下方空出 8px 灰色条。字号放大到 1.4 时 antd 自己把圆点放大到 24px，反而看不出问题，所以这只在默认字号下明显。

实测：

| 字号 | 轨道高 | 圆点高 | 上边距 | 下边距 |
|---|---|---|---|---|
| 1.0 | 28px | 18px | 2px | 8px |
| 1.4 | 28px | 24px | 2px | 2px |

**改动**：删除该 `min-height` 覆盖，恢复 antd 原生尺寸；点按范围改由新的 `.ai-connection-switch-row`（44px 高、`display: flex`、`gap: 8px`）承担。`AiConnectionSettings` 里原来包在 `<Space>` 中的开关改为 `<label className="ai-connection-switch-row">`，点文字也能切换。

**实测**：1.0 下轨道/圆点/上下边距为 `22 / 18 / 2 / 2`；1.4 下保持 antd 原生的 `28 / 24 / 2 / 2`。

## 3. 输入框占位文字折行后被下边框切掉

**现象**：窄屏下「描述你的安排，可附截图」折成两行，第二行被输入框下边框裁掉。

**根因**：输入框宽度被固定为 `calc(100% - 116px)`（附件与发送按钮占位），内边距再为麦克风让出 48px，320px 视口下可用于文字宽度约 106px，而占位文字 11 个字在 16px 字号下需要约 176px。`autoSize` 只按内容（空值）计算高度，占位符折行后溢出可视区。

**改动**：移动端占位改为「描述你的安排」；追加 `::placeholder { white-space: nowrap; text-overflow: ellipsis; overflow: hidden }`，保证任何宽度下都只占一行并省略，而不是折行后被裁。

## 4. 附带修正

窄屏且字号放大时，「未选择课表 + 选择课表后可按当前安排提问」右侧说明会被硬裁且没有省略号：父级 `overflow: hidden`，左侧标题不可收缩。改为左侧 `flex: 0 0 auto`、右侧 `.assistant-context-week { flex: 1 1 auto; min-width: 0 }`，恢复省略号。

## 验证

- `npm run typecheck`、`npm run lint`、`npm run build` 通过。
- 现有 220 项前端回归全部通过。
- 无头 Chromium 在 320 / 350 / 360 / 390 视口、字号 1.0 / 1.4 两档下复测：三个图标按钮居中偏移为 0；开关上下边距对称；占位文字单行；开关行高 ≥ 44px。

## 边界

- 只用浏览器与无头 Chromium 验证，未在 Android APK / Windows 外壳真机复验。
- 真机截图里页面底部那组「‹ ›」不是本应用的界面元素，而是内置浏览器自带的底部前进/后退工具条；本应用无法控制其显隐，安装为 PWA 可去掉。
- 图标按钮的文字仍是 `aria-label` 来源，若以后去掉 `aria-label`，需要另行提供可访问名称。
