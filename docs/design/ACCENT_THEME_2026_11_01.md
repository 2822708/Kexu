# 主题色可选（2026-11-01）

## 背景

现有界面的强调色固定为青蓝色 `#167d9a`。产品所有者表示不喜欢蓝色，但不同用户的偏好差异较大，因此不替换成单一颜色，而是把强调色做成用户可选项。

## 方案

设置 → 显示偏好 → 外观，新增“主题色”：

- 预设：默认青蓝、松针绿、苔绿、陶土、赭石、梅紫、石墨青。
- 自定义：0–360 色相滑块，饱和度固定。
- 偏好写入 `localStorage` 的 `timetable.accent`，只保存在当前设备；“重置”恢复默认。

颜色不是直接写死用户选的色值，而是由 `src/frontend/src/accent.ts` 在 OKLCH 空间推导：

- 浅色主题主色：白字对比度 ≥ 4.6:1；
- 浅底强调文字：与浅底对比度 ≥ 4.6:1；
- 深色主题主色：与卡片 `#172a35` 对比度 ≥ 5.4:1。

因此用户无法选到“看不清”的组合，也不需要自己配四种深浅。

## 应用范围

只重映射以下变量与 Ant Design token：

- CSS：`--accent`、`--accent-hover`、`--accent-ink`、`--accent-soft`、`--focus-ring`（浅色/深色各一套，通过 `:root[data-theme]` 注入）。
- Ant Design：`colorPrimary`、`colorInfo`、`colorLink`（链接用 ink），以及菜单选中底色与文字色、分段控件选中文字色。
- 落在 `--accent-soft` 或浅色页面背景上的文字使用 `--accent-ink`（对比度 ≥ 4.5:1）；`--accent` 只用于实底按钮、边框与图形。

未改动语义色（成功/警告/错误）与中性色，界面其余部分仍按原主题。

## 验证

- `npm run typecheck`、`npm run lint`（0 error）、`npm run build` 通过。
- 新增 `scripts/test-accent.mjs`，覆盖 0–350° 每 10°、三档饱和度的对比度下限、预设合法性与损坏偏好的解析；已加入 CI 的回归命令列表。
- 浏览器实测：浅色/深色主题下切换松针绿与赭石，导航选中态、标签下划线、按钮与链接随之更新；刷新后偏好保留。
- Impeccable 检测器对改动文件返回 0 条发现。

## 已知边界

- 只影响强调色；不改变暖/冷中性色，也不改变课表课程块的分类配色。
- 未提供吸色器或任意饱和度输入，避免产生无法校正的极端颜色。
- 尚未在 Android APK / Windows 外壳的真机上复验，验证范围为浏览器。
