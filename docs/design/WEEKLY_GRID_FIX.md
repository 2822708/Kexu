# 周课表遮挡修复验收

日期：2026-10-18。范围：共享周课表组件及其布局工具；本轮没有执行正式改名或全面换肤。

## 原因与修复

- 原冲突处理会隐藏部分重叠课程/考试。现在按每一天的重叠区间分配独立轨道，每条记录保留可点击入口，课程和考试使用不同类型的稳定键。
- 原跨节卡片依赖网格自动补位，后续日期可能错列。现在表头、节次、空格及安排全部使用显式行列坐标，稀疏节次也按已配置的行索引定位。
- 固定高度和溢出裁切会遮住长课名、地点及教师。现在行高随内容增长，文本换行，字号放大后仍可在课表区域滚动查看；不把十二节强塞进一屏。
- 作息外考试保留实际时间并标注邻近展示；无作息配置时仍提供已有安排列表。
