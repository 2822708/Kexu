# 窄屏课表：一屏看完整周（2026-11-11）

## 问题

课表网格在 `TimetableGrid` 里用内联样式写死了最小宽度：

```ts
minWidth: 56 + 7 * 112  // = 840px
gridTemplateColumns: `56px repeat(7, minmax(112px, 1fr))`
```

手机宽度约 390px，网格却有 840px，只能横向滚动；用户必须缩放才能看到完整一周。行高下限 68px × 12 节，竖屏也放不下全部节次。

同时页面上有几处次要信息占用了竖向空间：

- 标题下的学期起止日期与总周数
- 周次文字里的“/ 共 18 周”
- “点击课程或考试可查看或编辑；可横向滚动查看完整一周”提示
- 节次列的起止时间

## 改动

### 1. 网格尺寸改为响应式变量

`TimetableGrid.tsx` 不再写死像素，改用 CSS 变量参与计算：

```ts
minWidth: calc(var(--tt-axis-width) + lanes * var(--tt-day-min))
gridTemplateColumns: var(--tt-axis-width) + minmax(n * var(--tt-day-min), 1fr)
gridTemplateRows: auto + minmax(calc(var(--tt-row-min) * var(--tt-scale)), 1fr)
```

断点值（`timetable-grid.css`）：

| 宽度 | 节次列 | 每天最小宽 | 行高下限 |
|---|---|---|---|
| > 900px | 56px | 112px | 68px |
| ≤ 900px | 44px | 64px | 56px |
| ≤ 640px | 26px | 0px | 40px |
| ≤ 767 且高度 ≤ 720 | — | — | 34px |

### 2. 窄屏去掉次要信息

- 隐藏学期日期、总周数、网格上方提示
- 节次列只保留节号，不再显示起止时间
- 课程块隐藏地点/教师/节次副文本，只保留课程名与颜色
- 表头、工具条、页面间距压缩；`.tt-scroll` 改为 flex 容器，网格占满剩余高度

## 实测（iframe 模拟视口，本地数据 10 门课 / 12 节 / 7 天）

| 视口 | 横向溢出 | 纵向滚动 | 每天列宽 |
|---|---|---|---|
| 390×844 | 无 | 无 | 47px |
| 360×640 | 无 | 无 | 42px |
| 430×932 | 无 | 无 | 53px |
| 320×568 | 无 | 无 | 36px |

390×844 下测量：网格 `scrollWidth 356 = clientWidth 356`，`scrollHeight 577 = clientHeight 577`，7 个星期表头 + 12 个节次行全部在首屏内，10 个课程块无裁切。

## 边界

- 只在浏览器与模拟视口验证，未在真机复验。
- 极窄（≤360px）且课程名超过 5 字时，仍可能出现两行以内换行；隐藏了副文本以换取完整周视图。
- 桌面（>900px）维持原来的可读宽度与横向滚动策略。
