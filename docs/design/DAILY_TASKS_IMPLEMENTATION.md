# 课序日任务实现与验收

日期：2026-10-19。范围为本地主数据PWA，已将[交互草案](daily-tasks-concept.html)接入实际业务。Java桌面路径继续使用原今日页，不开放未具备服务端接口的新日计划。

## 实际行为

- 单列日任务，手机19px、桌面20px正文；52px完成控件。最多3项重点，用浅蓝绿底、细边条和星标区分。
- 临时任务只填标题即可保存在所选日，不生成假的23:59截止；支持已做补记、同名提示、中文输入法保护与失败保留输入。
- 长期待办显式选入日计划，只引用原待办；完成、撤销、循环下一期共用同一业务状态。支持移到下一天、未完成临时任务填写真实截止后转长期。
- 完成提交成功后才给440–460ms局部反馈和约6秒撤销；已完成列表仍能恢复待做。减少动画偏好取消粒子。重复请求、跨标签更新和恢复不重放庆祝。
- 待办页新增日任务索引，可找到其他日期尚未处理的临时事项，显式打开原计划日或移日。
- 底部一行日程、专注、今日回顾。前两项互斥展开，Esc收起并返回入口。专注手动开始、暂停、继续和结束，刷新可恢复；结束不完成任务，也不虚构专注分钟。
- 手动打开回顾，离线规则给具体事实小结，感受和文字由用户填写。保存和独立草稿分开；事实变化仅提示刷新，不覆写主观评价。跨标签旧编辑会话拒绝覆盖新版本，并提供明确放弃本页未保存修改的退出入口。
- 今天无可信主动活动且昨日有材料时，点击回顾才询问昨日；同数据集/业务日最多询问一次。昨日完整日期、只读，不合并今日数据。历史更正与补记需显式进入编辑，未来日不允许提前完成。
- 日期统一Asia/Shanghai。午夜保留原日计划和输入；已打开的回顾编辑会话保留原日及文字，不因日期变更卸载。

## 数据与兼容

沿用数据库名称 `tangent-timetable-local-v1`，IndexedDB版本升级为2，业务schema2增加`dataGeneration`、`dayEntries`、`dailyEvents`和`dailyReviews`。迁移在同一事务中保存原始v1值到`migration:v1:recovery`并写入新状态；非法旧数据整体回滚。旧数值ID、UUID、数据集身份和原完成状态保留，不凭`updatedAt`补造完成事件。

日任务、事件和回顾都在主库。每个命令带操作UUID、恢复代次和目标版本；显式设置完成状态，拒绝过期撤销。循环接续不会因撤销再完成重复生成。自动考试结束为system来源，不计主动成果；课程确认单列统计。来源删除后保留事件和标题档案。

新快照为logical snapshot2、scope `core-with-daily-v2`，包含全部日记录与回顾草稿。v1明文/密文仍可预览恢复，日记录留空并明确提示。加密信封和恢复密钥不变；恢复前保存恢复点，替换更新接收端代次，旧任务/回顾回调失效。7MB快照限制不靠删历史绕过。昨日询问偏好和计时状态保留为本机偏好，不进入业务快照。

升级时先关闭旧标签并加载新版本；旧代码不能以IDB版本1写回新版库。不要清除网站数据来解决升级问题。首次升级保留的原始状态是迁移恢复证据，普通用户继续使用已有文件导出/本机恢复点入口。

## 本轮验证

- 前端157项自动测试通过：本地核心、日任务15项、回顾18项、快照22项、AI提案、PWA、设备连接、日程、周表布局与导入。
- 部署/打包7项测试通过，包含新包schema/snapshot声明及旧构建拒绝。
- 实际浏览器验证：标题即存、重点、连续录入、完成→撤销→再完成只计一次、已完成恢复、回顾草稿刷新保留、保存后事实变化提示与手动刷新、跨标签旧评价拒绝覆盖、计时刷新仍运行、工具互斥和Esc焦点返回。
- 发行构建通过正式文件入口预览并恢复合成snapshot2；验证恢复后手动询问昨日、昨日完整日期与只读内容。恢复实测发现对象键顺序导致事实误报更新，已改为规范化比较，并加入快照往返指纹保持断言。
- TypeScript检查、手机构建和桌面Web构建通过；ESLint零错误，保留7条既有提示。构建仍提示Ant Design公共包略大于1200kB阈值，本轮没有为隐藏警告抬高阈值。
- 390px任务正文19px；320px三个工具同一行且高46px，无横向溢出或标题裁切；1280px为单列主体。
- 发行构建离线资源准备后，关闭5186本机服务并确认监听已停止：页面重新加载成功，新增临时任务、再次刷新仍保留、完成及本地回顾均可用。这是本机断服测试，不代表物理手机或生产网络验证。

## 交付与后续边界

运行包与SHA256校验将在发行记录列出；应在原网站origin升级，另一个端口/域名会得到另一份本机数据，不会自动迁移。

本轮没有原生APK、系统后台通知、可靠专注会话账本、AI回顾润色或自动跨设备合并。考试在日程中显示真实时间，尚未新增独立的考试参加确认账本。真机、200%系统字体、真实午夜连续使用和正式HTTPS升级仍需外部验收；业务日期/迁移/恢复逻辑的自动测试不能代替这些设备验证。
