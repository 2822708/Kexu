# 本地 AI 优化与验收计划

更新日期：2026-10-18。优先级依据本地主库与逐条确认边界；没有真实模型质量分数时，不以更换模型或加长提示词代替验证。

## 已在本轮实现

- 会话、消息、提案与执行状态落入本机IndexedDB；云快照服务不代理推理。
- 用户填写兼容服务、模型和本机Key，显式同意发送范围；图片能力另行勾选。连接测试走实际带鉴权SSE请求。
- 中文内置提示词集中版本管理；数据与指令分离，明确歧义澄清、日期边界、工作区、禁止脚本和禁止假装执行。
- 结构化回复严格校验、单条提案、不可变内容与目标基准、30分钟有效期、本地事务幂等；截断/取消/错误不保存可执行部分结果。
- 快速导入使用客户端可信意图，代码强制只接受新增待办/考试；材料或模型不能把导入操作升级为修改、删除、课程或脚本执行。
- 提供真实本机HTTP mock服务、可复现契约回归与12条语义用例；真实评测脚本默认不调用模型，需显式参数及专用评测凭据。

## P0：实际服务验收

需要拥有可用额度且允许目标站点CORS的用户自选服务。不能从共享服务器、真实用户数据目录或他人的配置提取Key。

1. 在目标手机Chrome及iOS Safari各做一次连接测试，记录浏览器/操作系统、供应商、精确模型、模型版本或快照名、时间和站点origin。不记录Key。
2. 为12个合成语义用例各运行3次，固定提示词版本与时间上下文，保留脱敏回答、提案、时延、错误率和用量。逐条人工核对日期、周次、实体、歧义与“待确认”的真实性。不能仅统计合法JSON率。
3. 先观察不执行，再对合成数据逐条确认；验证手动改数据后旧卡失效、刷新重开后状态保留、断网取消无部分结果、考试待办只生成一次。
4. 启用图片的模型另做清晰/模糊/旋转/含指令截图；OCR不确定标记必须保留，不能把OCR结果当可信授权。普通聊天模型不宣称有视觉能力。

准入底线：跨课表操作、CUSTOM脚本、凭据外泄、重复写入、未确认写入都必须为0；日期与歧义案例必须人工通过。若只完成契约层，不宣布供应商或提示词“评测通过”。

## P1：上下文与输出效率

当前按数量和字符限制截断，超大课表会给出明确错误。下一步实现本地检索：优先选择与问题关联的日期、课程、名称与实体ID；展示“本次发送了哪些集合与数量”，让用户在发送前减少范围。先测中文字符与实际token比例，依据所选模型的上下文窗口配置预算，不直接把字符数当token数。

维护一个统一动作schema，自动生成提示词字段说明和验证文档，避免课程长度、周次和偏移上限漂移。若供应商确实支持JSON schema/strict function calling，可为该提供方添加能力适配；本地验证与人工确认永远保留。对不支持的模型，不静默改为宽松自由文本执行。

流式正文当前缓冲到完整JSON验证后才展示。可改为两阶段“只读说明流＋独立结构化提案”，但必须保证第一阶段不冒充执行结果、不重复收费重试、取消后不落提案。先记录用户体验和失败数据，再增加复杂度。

## P2：运行体验与长期回归

支持用户为不同端点保存独立能力档案（SSE结束语义、视觉、schema支持），禁止自动跨提供方回退或发送Key给新origin。增加可取消连接测试、合理的指数退避提示与费用显示，默认不自动重试生成请求。

把真实运行脱敏失败样例纳入回归：长中文课名、同名课程、跨学期日期、月末循环、考试变更、附件内提示注入、多标签页竞争、应用更新和恢复后旧卡。每次提示词变更必须重跑同一语义集，比较各项结果而不是只看平均得分。

## 执行命令

在 `src/frontend` 中：

```text
node --test scripts/test-local-ai.mjs
node scripts/mock-openai.mjs
node scripts/eval-local-ai.mjs
```

第三条默认只输出凭据是否存在的布尔值并明确不运行。真实评测需在用户自己的终端以私有环境变量设置 `AI_EVAL_ENDPOINT`、`AI_EVAL_MODEL`、`AI_EVAL_API_KEY`，再执行 `node scripts/eval-local-ai.mjs --live`。默认报告写入已忽略的 `work/ai-live-eval.json`；只用合成数据。不要在命令行参数、截图、Git提交或聊天中放Key。报告自动检查协议/schema和预期动作类型，仍需人工语义评分。
