## v4 做了什么（对照竞赛答辩通行做法）

参考两份公开的国赛答辩稿指南（[丘奖答辩全指南](https://qctkxj.org.cn/news/819.html)、[国赛评委看什么](https://www.zkzhiyan.com/news-info?id=475)）后落地：

1. **12 个标题改成结论句**——例如"证据分两层：工程已验证，效果未验证"，让每页自己把观点说完（"单页突出一个核心观点、30 秒可读"）。
2. **新增开场结论页 P2**：问题 / 做法 / 现状各一句。评委只记一页的话，就是这页。
3. **新增 P11「和直接问模型比，差别在模型之外」**：把评委最常问的一题前置成对比页（直接对话 vs 本系统）。
4. **每页加页脚** `Campus Agent｜AIC-2026-15513467｜n/20`，方便翻页定位与控节奏。
5. 数据、截图、附录口径全部不动；P14 脚注仍把 v0.2（234/37/3）与 Kexu v0.5（173）两套口径分开。

结构对照（"十几页、每段 1–2 页、局限主动写"）：正文 16 页 ≈ 9 分钟按 30–35 秒/页；附录 4 页只用于提问。
