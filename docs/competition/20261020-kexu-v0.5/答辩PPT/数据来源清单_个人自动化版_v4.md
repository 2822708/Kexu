## 三、口径约定（答辩口径）

1. **工程通过数 ≠ 模型准确率 ≠ 用户收益**，三者不互相替代。
2. **两套证据分开报**：v0.2 归档（234/37/3，Java 后端 + H2）与 Kexu v0.5（173 前端回归、语义评测 `not_run`，本地 IndexedDB）对应不同代码与版本。
3. **"已实现 / 规划 / 待验证"三档**必须在页面上可分辨；未实现能力不写完成时态。
4. **本地主库不等于数据不出设备**：联网推理会把所选上下文发送到用户自选的模型服务。
5. **匿名**：全片不含学校名称、校徽、指导教师、队员姓名与真实学生数据。
