# 快照与恢复安全复核

复核范围：`src/cloud`、`src/frontend/src/backup`、`src/frontend/src/local/snapshots` 及 `LocalBackupSettings`。主库、AI 和服务器实际部署由其他任务独立验收。本次没有读取真实用户数据或恢复凭证。

## 发现并修复

1. **不可变对象的大小写碰撞**：原先接受大写 UUID，在 Windows 等忽略大小写的磁盘上可用大小写变体覆盖同一文件。服务现仅接受规范小写 UUID；新增测试验证旧内容不变。
2. **并发请求的缓冲内存**：原先上传在进入串行写区前读取完整 body，多请求可消耗共享主机内存。新增 2 上传、2 下载及 16 连接上限，30 秒响应超时；测试验证被拒请求没有占用新槽位、断连释放槽位。
3. **数据文件与索引持久化顺序**：现写临时文件并 fsync，再 rename；密文先于索引提交。Linux 对父目录 fsync。测试验证正常重启后的 hash/大小与内容一致；未模拟断电，不宣称已通过断电故障注入。
4. **上传期间切换空间**：旧作用域回包已被拒，但新空间启用请求可能因旧上传占用协调器而被跳过。现记录待重跑标记，旧上传结束后自动运行新作用域；真实 HTTP 测试验证旧回包不写新水位、新空间会自动备份。
5. **恢复点列表内存**：十份大快照曾在打开设置时一次载入。备份 DB v2 增加小型恢复点元数据，UI 只在用户选定时读取一份完整快照；升级事务保留 v1 队列、凭据及恢复负载。测试覆盖 v1 升级和同时间戳保留最新恢复点。
6. **备份数据库升级阻塞/关闭**：增加 blocked 错误与 versionchange 重连，避免设置页静默等待关闭的连接；备份存储错误不会让主库修订显示被旧值遮蔽。
7. **应用更新恢复点**：提供 `saveCurrentRestorePoint(expectedRevision?)`，完全本地执行，保存前后检查修订；云不可用不会影响创建，失败应阻止切换应用版本。

## 已核对的保护

- vault token 随机 256 bit，仅存 SHA-256，比较采用固定长度 timingSafeEqual；对象 UUID 不作为授权。列表、下载、删除均绑定 token 的 vault，外部对象与未知对象同为 404。
- 路径来源只有 UUID；不接受路径或查询参数凭据。请求体、大小、对象数、空间数、单空间/全站总量和速率均受限；并发配额检查在同一串行提交区。
- 仅公开加密快照封装及必要元数据，不接受业务 CRUD/AI 代理，私有目录没有静态读取接口。正式 Nginx 只转发 `/api/v1/` 且保留前缀，同一 HTTPS origin；不启用通配 CORS。
- AES-256-GCM 随机 96 bit IV / 128 bit 标签，版本、ID、数据集、修订、时间等元数据受附加认证；字段白名单排除凭据与可执行 AI 状态。
- 本地事务独立于云上传；持久任务保留原密文、ID、hash；回执比较 ID/大小/hash/修订/数据集，水位取 max 且按 scope 校验，旧回包不清除新任务。
- 恢复只在用户确认后运行，先留恢复点；预览及替换事务都检查修订，恢复点失败中止，非法数据由主库校验和事务回滚保护。本机身份/云凭据不被快照替换。

## 运行边界与后续

- 推荐首批共享主机配额为全站 256 MiB、每空间 32 MiB/20 份、16 个空间，见 `deployment.env.example`。Nginx 来源 IP 下注册限额为全站 3 次/天；新成员超过该数量需管理员调整配额并保留 Nginx 按访客限流。
- 单进程独占私有目录；不能用多个实例共享文件索引。目录实际磁盘用量也要监控；异常强杀可能留下未索引临时文件，需在停服备份后由管理员核查，不在线自动删除未知内容。
- 仅有 capability 凭证，尚无自助 token 轮换/账户找回；凭证丢失无法解密，泄露后需管理员撤销旧空间并创建新空间。此边界在 UI/README 明确告知。
- 云快照不是实时合并。快照不含 AI 历史/附件/偏好；恢复会明确清空当前 AI 聊天。更新前恢复点也只覆盖核心数据。
- 关闭 PWA 后不承诺定时上传。IndexedDB 仍受浏览器清理策略影响，恢复凭证与本地导出必须另存。
- 本轮测试为 Node + fake-indexeddb 与真实 localhost HTTP，不替代生产 HTTPS、Nginx、手机安装/存储与真机浏览器验收。
